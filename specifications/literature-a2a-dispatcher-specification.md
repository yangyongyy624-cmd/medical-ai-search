# 文献检索 A2A 调度器规范

> 更新于 2026-08-09 | 稳定版 v6.0

## 核心原则

**全面 > 速度** — 用户要的是全面、准确、内容丰富，不是快。

## 架构：6 路并行 + 全文验证

| 路数 | 来源 | 任务分工 | 阻塞性 |
|:---:|:---|:---|:---:|
| **0** | 本地知识库 | Obsidian 知识库基线 | 阻塞 |
| **1** | OpenAlex | 反向追踪（参考文献） | 阻塞 |
| **2** | CrossRef | 反向追踪（DOI） | 阻塞 |
| **3** | PubMed | 临床文献核心库 | 阻塞 |
| **4** | Europe PMC | 补充文献 | 阻塞 |
| **5** | Semantic Scholar | 正向追踪（引用文献） | 阻塞 |

> **v6.0 更新 (2026-08-09)**：
> - Agent 0：搜索本地知识库，提取 PMID + 标题 + 期刊 + 年份 + 标签
> - 全文获取验证：批量 EuropePMC + 并发 PMC efetch，标记免费/机构订阅
> - 报告时间戳：自动生成检索时间，方便对比多次检索结果

## 评分系统 v6.0

### 评分公式（满分 60）

| 加分项 | 条件 | 分值 |
|--------|------|------|
| **期刊影响力**（最高 25 分） | 顶刊：NEJM/Lancet/JAMA/Nature/Science/BMJ | 25 |
| | 临床顶刊：Anesthesiology/BJA/Anaesthesia/ICM/Crit Care 等 | 15 |
| | 中坚期刊：J Clin Anesth/Eur J Anaesthesiol/Acta Anaesthesiol 等 | 8 |
| **被引次数**（最高 20 分） | >500 次 | 20 |
| | >200 次 | 18 |
| | >50 次 | 12 |
| | >0 次 | 3 |
| **年份**（最高 10 分） | 2025+ | 10 |
| | 2023-2024 | 7 |
| | 2020+ | 5 |
| **本地已验证**（最高 5 分） | 知识库中已有全文/阅读报告 | 5 |

### 三级显示

| 等级 | 分数 | 说明 |
|------|------|------|
| 🔴 高影响力 | ≥32 分 | 顶刊/高引用核心文献 |
| 🟡 中影响力 | 25-31 分 | 临床顶刊/中坚期刊 |
| ⚪ 一般 | <25 分 | 普通期刊/低引用 |

## 去重逻辑

- **DOI 精确匹配**（最严格）
- **PMID 精确匹配**
- **标题不区分大小写匹配**

## 全文获取验证

- **🆓 免费获取**：PMC 开放获取 / Europe PMC / 本地知识库
- **🏥 机构订阅**：军事医学图书馆（https://yc.mlpla.mil.cn）
- 批量 EuropePMC + 5 线程并发 PMC efetch，60 秒内完成
