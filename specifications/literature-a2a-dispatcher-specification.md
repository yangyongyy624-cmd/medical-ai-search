# 文献检索 A2A 调度器规范

> 创建于 2026-08-04 | 更新于 2026-08-09 | 最终版 v6.0 | 铁律级别

## 核心原则

**全面 > 速度** — 用户要的是全面、准确、内容丰富，不是快。

## 最终架构：6 路主链 + 1 路云端辅助（非阻塞）

| 路数 | Agent | 身份 | 任务分工 | 阻塞性 |
|:---:|:---:|:---:|:---|:---:|

| **4** | **Tiny** | 宵宵分身 | **全文验证** (fetch_articles) | 阻塞 |

## 三层强约束

### 1. 工具层约束（最强制）
```toml
disallowed_tools = [
    "mcp__pubmed__pubmed_search_articles",
    "mcp__pubmed__pubmed_europepmc_search",
]
```
禁搜索，保留辅助（fetch_articles / fetch_fulltext / find_related / lookup_mesh / convert_ids）

### 2. 提示词层约束
cc-connect `system_prompt` 铁律：A2A 唯一入口 + 多轮迭代 + 全文验证 + 标红

### 3. 流程层约束
a2a-dispatcher 派发 7 路主链 + 1 路云端辅助。Claude Code 仅作为指挥官（理解需求→调度→整合），不碰任何 API 调用。

## 唯一正确方式
```bash
~/.a2a/bin/a2a-dispatcher search "关键词"
```

## 评分系统 v4.2

### 评分公式（满分 60）

| 加分项 | 条件 | 分值 |
|--------|------|------|
| **期刊影响力**（最高 25 分） | 顶刊：NEJM/Lancet/JAMA/Nature/Science/BMJ | 25 |
| | 临床顶刊：Anesthesiology/BJA/Anaesthesia/ICM/Crit Care 等 | 15 |
| | 中坚期刊：J Clin Anesth/Eur J Anaesthesiol/Acta Anaesthesiol 等 | 8 |
| **被引次数**（最高 20 分） | >500 次 | 20 |
| | >200 次 | 18 |
| | >50 次 | 12 |
| | >0 次 | 3 |
| **年份**（最高 10 分） | 2025+ | 10 |
| | 2023-2024 | 7 |
| | 2020+ | 5 |
| **本地已验证**（最高 5 分） | Obsidian 知识库中已有全文/阅读报告 | 5 |

### 三级显示

| 等级 | 分数 | 说明 |
|------|------|------|
| 🔴 高影响力 | ≥32 分 | 顶刊/高引用核心文献 |
| 🟡 中影响力 | 25-31 分 | 临床顶刊/中坚期刊 |
| ⚪ 一般 | <25 分 | 普通期刊/低引用 |

### Agent 0 本地检索（v5.0 新增）

**功能**：在 5 路 API 检索之前，先搜索本地 Obsidian 知识库
- **匹配方式**：中文关键词分词 + 英文关键词拆分
- **提取字段**：PMID + DOI + 标题 + 期刊 + 年份 + 标签
- **本地验证标记**：`✅本地已验证`
- **评分优势**：本地已验证文献额外 +5 分

**实测效果**（"dexmedetomidine sedation ICU"）：
| 指标 | 结果 |
|------|------|
| Agent 0 本地 | 45 篇 |
| 5 路 API | 111 篇 |
| 去重后 | 150 篇 |
| 本地已验证 | 39 篇 |
| PMID 列表 | 65 个 |

### 三级显示

| 等级 | 分数 | 说明 |
|------|------|------|
| 🔴 高影响力 | ≥32 分 | 顶刊/高引用核心文献 |
| 🟡 中影响力 | 25-31 分 | 临床顶刊/中坚期刊 |
| ⚪ 一般 | <25 分 | 普通期刊/低引用 |

### 为什么期刊优先？

**问题**：v3.x 被引次数权重占 80% 以上，新文献（0 引用）直接掉到 ⚪ 档被漏掉。即使顶刊文章也因为发表时间短被误伤。

**解决**：期刊影响力 > 被引次数 > 年份。NEJM 2025 年新文章（0引用）= 25+0+10 = 35 分（🔴），不会被漏掉。

### 实测分布（150篇去重后）

| 等级 | 篇数 | 占比 |
|------|------|------|
| 🔴 | 21 篇 | 21% |
| 🟡 | 33 篇 | 33% |
| ⚪ | 46 篇 | 46% |
