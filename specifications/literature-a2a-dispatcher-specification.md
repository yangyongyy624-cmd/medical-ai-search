# 文献检索 A2A 调度器规范

> 更新于 2026-08-10 | 稳定版 v6.1

## 核心原则

**全面 > 速度** — 用户要的是全面、准确、内容丰富，不是快。

## 架构：6 路并行 + 全文验证 + 审核规则

| 路数 | 来源 | 任务分工 | 阻塞性 |
|:---:|:---|:---|:---:|
| **0** | 本地知识库 | 知识库基线检索 | 阻塞 |
| **1** | OpenAlex | 反向追踪（参考文献） | 阻塞 |
| **2** | CrossRef | 反向追踪（DOI） | 阻塞 |
| **3** | PubMed | 临床文献核心库 | 阻塞 |
| **4** | Europe PMC | 补充文献 | 阻塞 |
| **5** | Semantic Scholar | 正向追踪（引用文献） | 阻塞 |

## 三层强约束

### 1. 工具层约束
```toml
disallowed_tools = [
    "search_articles",    # 禁止直接搜索
    "europepmc_search",   # 禁止直接搜索
    "lookup_citation",    # 禁止引用查找
    "lookup_mesh",        # 禁止 MeSH 查找
    "spell_check",        # 禁止拼写检查
]
```
**原则**：禁止所有搜索类工具，保留辅助工具（fetch_articles / fetch_fulltext / find_related / convert_ids / format_citations）

### 2. 提示词层约束
system_prompt 铁律：唯一入口 + 多轮迭代 + 全文验证 + 标红 + 杠精审核 + 交叉验证

### 3. 流程层约束
调度器派发 6 路并行检索。Agent 仅作为指挥官（理解需求→调度→整合），不碰任何 API 调用。

## 评分系统 v6.1

### 评分公式（满分 60）

| 加分项 | 条件 | 分值 |
|--------|------|------|
| **期刊影响力**（最高 25 分） | 顶刊：NEJM/Lancet/JAMA/Nature/Science/BMJ | 25 |
| | 临床顶刊：Anesthesiology/BJA/Anaesthesia/ICM/Crit Care 等 | 15 |
| | 中坚期刊：J Clin Anesth/Eur J Anaesthesiol/Acta Anaesthesiol 等 | 8 |
| **被引次数**（最高 20 分） | >500 次 / >200 次 / >50 次 / >0 次 | 20 / 18 / 12 / 3 |
| **年份**（最高 10 分） | 2025+ / 2023-2024 / 2020+ | 10 / 7 / 5 |
| **本地已验证**（最高 5 分） | 知识库中已有全文/阅读报告 | 5 |

### 三级显示

| 等级 | 分数 | 说明 |
|------|------|------|
| 🔴 高影响力 | ≥32 分 | 顶刊/高引用核心文献 |
| 🟡 中影响力 | 25-31 分 | 临床顶刊/中坚期刊 |
| ⚪ 一般 | <25 分 | 普通期刊/低引用 |

## 审核规则（v6.1 新增）

### 杠精审核
- 验证每个 DOI、作者、年份、主张是否被原文支持
- ≥2篇独立文献支持才算结论成立
- 必须搜索相反观点
- 必须检查方法学质量
- 必须标注文献局限性

### 交叉验证
- 所有关键结论必须有≥2个独立来源支持
- 所有医学统计数据必须有文献支持
- 所有治疗声称必须核实适应症是否获批
- 所有机制描述必须有实验证据支持
