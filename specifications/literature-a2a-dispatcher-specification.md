# 文献检索 A2A 调度器规范

> 创建于 2026-08-04 | 更新于 2026-08-09 | 最终版 v5.0

## 核心原则

**全面 > 速度** — 用户要的是全面、准确、内容丰富，不是快。

## 架构

6 路检索：1 路本地知识库 + 5 路 API（OpenAlex + Semantic Scholar + CrossRef + Europe PMC + PubMed）→ 自动去重 → 期刊优先评分 + 本地验证 → 输出 Top 100 → 供 AI 做引用链迭代。

### Agent 0 本地知识库（v5.0 新增）

在 5 路 API 检索之前，先搜索本地知识库：
- **匹配方式**：中文关键词分词 + 英文关键词拆分
- **提取字段**：PMID + DOI + 标题 + 期刊 + 年份 + 标签
- **本地验证标记**：`✅本地已验证`
- **评分优势**：本地已验证文献额外 +5 分

### 唯一正确方式
```bash
a2a-dispatcher search "关键词"
```

## 评分系统 v5.0

### 评分公式（满分 60）

| 加分项 | 条件 | 分值 |
|--------|------|------|
| **期刊影响力**（最高 25 分） | 顶刊：NEJM/Lancet/JAMA/Nature/Science/BMJ | 25 |
| | 临床顶刊：Anesthesiology/BJA/ICM/Crit Care 等 | 15 |
| | 中坚期刊：J Clin Anesth/Eur J Anaesthesiol 等 | 8 |
| **被引次数**（最高 20 分） | >500/200/50/0 次 | 20/18/12/3 |
| **年份**（最高 10 分） | 2025+/2023-24/2020+ | 10/7/5 |
| **本地已验证**（最高 5 分） | 知识库中已有全文/阅读报告 | 5 |

### 三级显示

| 等级 | 分数 | 说明 |
|------|------|------|
| 🔴 高影响力 | ≥32 分 | 顶刊/高引用核心文献 |
| 🟡 中影响力 | 25-31 分 | 临床顶刊/中坚期刊 |
| ⚪ 一般 | <25 分 | 普通期刊/低引用 |

### 为什么期刊优先？

被引次数权重过高会导致新文献天然吃亏。2025 年新文章即使发表在 NEJM，因为被引=0 也会被排到最后。改为期刊影响力优先后，顶刊新文章（0引用）自动排到前面。
